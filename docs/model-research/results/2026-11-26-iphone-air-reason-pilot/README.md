# Physical iPhone Air — 16-case closed-answer reasoning pilot

Four providers, identical original synthetic prompts, four each arithmetic, planning, state transitions and evidence; 8 DE and 8 EN. Strict final string matching with whitespace trimming and comma-space normalization, no explanation allowed. Apple greedy 96-token maximum (actual generated token count unavailable); Qwen3.5, Qwen3 and MiniCPM5 greedy 96-token maximum with explicit thinking disabled. This compares a short-answer condition, not best possible reasoning. Wrong answer and formatting errors are not distinguished, raw output is not retained. All 64 cases completed, no actions executed. Apple 8/16, Qwen3.5 2/16, MiniCPM5 2/16, Qwen3 1/16. Debug lab, no controlled thermal protocol, no energy or memory measurements in this suite. Native Apple and MLX generation APIs differ. No general qualification or independent statistical holdout; separate from the 24-case agent pilot. Receipts contain only metadata. Source hash is not hardware attestation.
