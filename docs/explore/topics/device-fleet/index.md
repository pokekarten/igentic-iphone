# Managed Device Diagnostics

**Today:** iPhone Connect supports typed local MCP diagnostics, fixture-backed approval policy tests and fixed-owned-app navigation proposals. A successful fixture or simulator test does not prove physical iPhone connectivity.

**B2B use case:** a support operator requests a coarse diagnostic state from an explicitly enrolled and authorized company app, reviews a bounded action and checks a receipt.

**Missing before a pilot:** company enrollment and identity, device/session ownership, managed app distribution, documented wired/network channels, admin logging and independent physical-device acceptance. Do not confuse Apple Business/MDM configuration with arbitrary taps across apps or remote cellular access.
