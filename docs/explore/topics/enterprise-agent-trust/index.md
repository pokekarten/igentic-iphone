# Enterprise Agent Trust

**Today:** the research kernel includes Swift policy decisions, approval boundaries and bounded audit concepts; system App Intents and integration tests remain in review. This is not an enterprise SDK or a production deployment.

**B2B use case:** a staff member reviews a synthetic task proposed by local AI; Swift code decides which capabilities can be exercised and a human explicitly approves a bounded write. A model suggestion never grants permissions.

**Missing before a customer pilot:** independently verified tenant and role enforcement, organization identity, managed app configuration, server-side authorization, data-processing terms, audit export and security testing. No generic control of other iPhone apps is promised.

See the repository's B2B solution portfolio for proof gates and ownership boundaries.
