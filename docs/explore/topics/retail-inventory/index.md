# Retail Inventory Assistant

**Today:** iGentic can locally display bundled discovery content, but no commerce adapter, stock database, customer catalog, live scanner or point-of-sale system is connected.

**B2B use case:** store staff review a synthetic product identity and source evidence before suggesting a catalog correction. A future adapter must verify rights, ownership and actor role before any change.

**Missing before a pilot:** rights-cleared catalog data, identity and variant validation, tenant-level stock permissions, scanner quality benchmarks, API contracts, idempotency and approval for inventory writes. No payments or automated listings are authorized.
