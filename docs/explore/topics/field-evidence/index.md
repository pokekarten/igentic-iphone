# Field Evidence Workbench

**Today:** the separate Fieldglass prototype provides native Vision/OCR experiments, draft editing, fixed-app MCP tools and synthetic receipt verification in the simulator. Physical iPhone/ChatGPT acceptance is not established.

**B2B use case:** an inspector reviews a fictional asset observation, corrects a draft and decides whether to retain or cancel it. The original source, user action and verified outcome must remain distinguishable.

**Missing before a pilot:** consent, image and location minimization, retention, provenance hashing, offline failure handling, device installation and verified role-bound backend authorization. No real customer images or claims are bundled.
